About OnlyLogins

Why build OnlyLogins?

OnlyLogins is a free and open source password manager, available both online and self-hosted. The project is centered around the core principle that your secure login credentials should be protected by a passphrase that you memorize, not by physical devices and not by your email account. 2FA dongles get lost, email accounts lock you out, and without them other password managers will leave you out in the cold.

With OnlyLogins your account and data are secured by your passphrase. The passphrase you use to log in is also used to encrypt your data. This security model implies a lost keyfob or disabled / compromised email account is not going to lock you out of your password manager. As long as you can remember your passphrase, you can access your login information from any web browser. But if you forget your passphrase, no one, not even the OnlyLogins website operator, can help recover your data. That is the strong tradeoff, and is what makes the security model work.

The OnlyLogins source code is available on GitHub under the AGPL-3.0. You can use onlylogins.net for free, or run your own instance on hardware you control. The most secure place for your data is your own network.

Security without a second factor

When creating an account, you must come up with a passphrase that is at least 16 characters long. That's a lot! The length matters more than complexity. Password fields requiring an upper case letter, a number, a punctuation symbol are missing the point. The classic XKCD comic describing passwords explains the security model perfectly. Using a few random words is more secure than mashing random letters and numbers together. See the help page for more guidance.

If you do not understand some of the terms in this section, just know that OnlyLogins is using industry standard security practices. Your passphrase is never stored by OnlyLogins. When your account is created, OnlyLogins derives a 256-bit encryption key by combining your passphrase with a generated per-user salt. It stores that salt and a verifier in the database and uses them to verify future logins. Your passphrase and the derived key never get written to disk, period. The secret values that you store, such as passwords, usernames, etc. are encrypted with that AES-256-GCM key before being stored in the database. It is not possible to decrypt them without your memorized passphrase.

The folder and document names you create are stored as plain text, so that OnlyLogins can help keep things organized. These must not be used to store sensitive information. If a copy of the database were to be exposed, the secret values you store remain unreachable without your passphrase. The mandatory 16-character minimum makes guessing that passphrase very impractical, even for super computers.

There is no account recovery mechanism. If you forget your passphrase, there is nothing anybody can do to help you. There is no backdoor because there is nothing that can be done with the encrypted data without your passphrase. Keep your own offline backups using the export feature. Store them in a physical fireproof safe in your home.

Usage guidelines

A password manager concentrates a lot of sensitive information in one place.
Follow these guidelines to keep it that way.

  • Use a unique passphrase. Never reuse your OnlyLogins passphrase on another site, and do not store it in another online service. Make sure it stays out of email, chat logs, screenshots, and iCloud.
  • Do not use AI agents. OnlyLogins is designed for a human using a normal web browser. Each one of those AI agents (like Meta Muse) can read everything on every web page you visit, and uploads the content to their servers. You are trusting entities like Meta to not abuse your data.
  • Use a trusted device. Only use a laptop, tablet, or phone that you own and control. Keep them updated regularly. If you MUST use a shared device, use the web browser in incognito mode, and fully exit the browser when you are done. Reboot the device if you can. Avoid using public computers, such as at a library.
  • Do not scrape or spam the service. High-volume requests, vulnerability scanners, and automated crawlers waste resources and may be rate-limited, blocked, or banned by IP.
  • Maintain your own backups. Use the export feature regularly. The exported file is not encrypted. It contains every secret in your account, so store it in a physical safe in a secure location. Delete old offline copies when you no longer need them.
  • Report security problems privately. If you believe you have found a vulnerability, please contact seth@cattlecloud.net before sharing the details publicly.

Supporting OnlyLogins

OnlyLogins is free to use, and the code is open source. Hosting, domains, and development are paid for by people who find the project useful. If you would like to support the project, subscribe to the Patreon plan for $2 per month. Patreon subscribers also get a higher document limit. There is no obligation, and the free plan remains fully usable.
